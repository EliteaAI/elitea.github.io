**EPAM MCP Servers** are ready-to-use MCP server connections for EPAM internal services and tools. Unlike remote MCP servers that require you to supply a server URL and credentials manually, EPAM MCP Servers are pre-configured by your ELITEA environment: connection settings (server URL, OAuth credentials) are automatically supplied at runtime so you can get started with just a few clicks.

## Available EPAM MCP Servers and Their Tools

EPAM MCP Servers are available at [next.elitea.ai](https://next.elitea.ai/) and are accessible only to EPAM employees. Authentication requires an active EPAM corporate account via the EPAM identity provider.

### EPAM MCP Server Tools

Each EPAM MCP server exposes a set of tools that agents can invoke to interact with the corresponding EPAM internal service.

<Warning title="Access depends on your EPAM account permissions">
Available tools and returned data depend on your EPAM corporate account permissions. If you lack access to an EPAM MCP server, tools will not load and you will see:

![EPAM MCP No Access](../../img/integrations/mcp/epam-mcp/epam-mcp-no-access.png)

Contact your EPAM administrator to request the necessary access.
</Warning>

<Note>
Each accordion below corresponds to one EPAM MCP server. Expand an accordion to browse the tools available for that server.
</Note>

## How to Work with EPAM MCP Servers

ELITEA provides a simple flow for connecting to and configuring EPAM MCP servers. Once a toolkit is created, you can use it in chat conversations or attach it to agents for automated workflows.

### Connect a New EPAM MCP Server

<Note>
The setup and creation flow is the same for all EPAM MCP servers. Follow the steps below once to create any EPAM MCP toolkit — simply select the desired server in Step 1.
</Note>

<Steps>

<Step title="Open the Toolkits panel and select the EPAM MCP type">
1. Navigate to your ELITEA project and open the **Toolkits** panel from the left sidebar.
2. Click **+ Create** to open the toolkit creation dialog.
3. Select the **MCP** category.
4. Choose the EPAM MCP you want to connect:

     <img src="../../img/integrations/mcp/epam-mcp/epam-mcps_connect_list.png" alt="EPAM MCP Connect List" />
</Step>

<Step title="Authorize">
An **MCP Authorization** pop-up will appear showing the server URL and an optional **Scope** field:

1. Select **Authorize** in the pop-up.
2. In the EPAM OAuth sign-in window, approve the requested permissions.

The sign-in window closes and ELITEA retrieves the list of available tools from the MCP server.

<img src="../../img/integrations/mcp/epam-mcp/epam-mcps_connect_auth.png" alt="EPAM MCP Authorization" />

<Warning title="Authorization expires after 59 minutes">
EPAM MCP access tokens expire after 59-minutes. Long-running operations or scheduled tasks may lose access and require re-authorization. For uninterrupted access, plan tasks accordingly and be prepared to re-authenticate when prompted.
</Warning>
</Step>

<Step title="Enter a name and description">
The toolkit configuration form opens with two fields to fill in:
- **Toolkit name** *(required)* — enter a name to identify this toolkit in your project
- **Description** *(optional)* — add a short description to help your team understand what this toolkit is for

<img src="../../img/integrations/mcp/epam-mcp/epam-mcps_connect_name.png" alt="EPAM MCP Name and Description" />

<Note>
All connection settings (server URL, OAuth credentials) are handled automatically by ELITEA — there is nothing else to configure.
</Note>
</Step>

<Step title="Select tools and save">
After authorization, the full list of tools provided by the MCP server appears as a checklist.

Select the tools you want to make available in ELITEA, then select **Save** to create the toolkit.

<img src="../../img/integrations/mcp/epam-mcp/epam-mcps_connect_tools.png" alt="EPAM MCP Select Tools" />

The EPAM MCP toolkit is now ready to use in chats and agents.

<Note>
If you create the EPAM MCP toolkit inside a **team project**, it will be available to all members of that project — they can add it to their agents and chat conversations without needing to set it up individually.
</Note>
</Step>

</Steps>

### Test EPAM MCP Server Tools

After you save your EPAM MCP toolkit, you can test its tools from the toolkit detail page. By testing, you verify that authorization works and validate tool behavior before you add the toolkit to a chat or an agent.

<Info>
EPAM MCP servers are tested the same way as any other toolkit.
</Info>

To test an EPAM MCP tool:

1. On the toolkit detail page, select **Test**.
2. In the **Test Settings** panel, select **Select Tool**, and search for the tool you want to test.
3. Select a model, and complete the parameter fields for the tool.
4. Select **Run Test**.

The **Results** panel shows the request and response for each run.

<video controls>
  <source src="../../img/integrations/mcp/epam-mcp/epm-mcp_test-tools.mp4" type="video/mp4"/>
</video>

**Best practices**

* Verify that EPAM OAuth authorization is configured correctly.
* Test tools and their parameters and see actual responses from the EPAM MCP server.
* Debug the tool behavior and understand output formats before integrating with agents.

<Info>
For detailed instructions on how to use the Test Settings panel, see **[How to Test Toolkit Tools](../../how-tos/credentials-toolkits/how-to-test-toolkit-tools)**.
</Info>

### Use EPAM MCP Servers in Chat

<Info>
EPAM MCP servers are added to chats as **Toolkits**, not as *MCPs*.
</Info>

To add an EPAM MCP toolkit to a chat:

1. In the sidebar, select **[Chat](../../menus/chat)**.
2. Select **+ Chat** or open an existing chat.
3. In the message input toolbar, select **+** > **Toolkits**.
4. Search for your configured EPAM MCP toolkit, and select the toggle next to it.

The toolkit is added to the conversation, with its configured tools enabled.

<video controls>
  <source src="../../img/integrations/mcp/epam-mcp/epm-mcp_add-chat.mp4" type="video/mp4"/>
</video>

To use the toolkit, ask a question or request an action that calls one of its tools. If OAuth authorization is required, a pop-up opens: complete the sign-in, and the response continues.

### Use EPAM MCP Servers in Agents

<Info>
EPAM MCP servers are added to agents as **Toolkits**, not as *MCPs*.
</Info>

To add an EPAM MCP toolkit to an agent, you must first create and save the agent.

To add an EPAM MCP toolkit to an Agent:

1. In the sidebar, select **[Agents](../../menus/agents)**.
2. Create an agent, or open an existing one.
3. In the **Tools** section of the agent configuration, select **+ Toolkit**.
4. Search for your configured EPAM MCP toolkit, and select it.

The toolkit is added to the agent, with its configured tools enabled.

<video controls>
  <source src="../../img/integrations/mcp/epam-mcp/epm-mcp_add-agent.mp4" type="video/mp4"/>
</video>

The agent can call EPAM MCP tools when it answers user queries.
