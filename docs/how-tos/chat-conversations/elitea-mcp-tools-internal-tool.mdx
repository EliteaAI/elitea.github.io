## Overview

**Elitea MCP Tools** is a built-in internal tool that exposes ELITEA platform management capabilities as MCP (Model Context Protocol) tools directly inside a conversation. Once enabled, the AI can use these tools to manage ELITEA resources — agents, pipelines, chat conversations, and toolkits — without the user leaving the chat interface.
