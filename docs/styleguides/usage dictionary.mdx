# Word lists and usage dictionary

## Differentiate between

- Access levels, roles, and permissions. Each user has an access level and is assigned a role. Each role includes a set of permissions.
- *Create* (new, opposite of delete) and *add* (existing, opposite of remove).
- *Download* and *export*.
- *Open* and *expand*.
- *Must* (required), *is recommended* or *should* (recommended), and *can* (optional).

## Useful words

- Use *can* instead of *be able*.
- Use *dialog* instead of *dialog box*, *modal*, *modal dialog*, *modal window*, *pop-up*, *pop-up window*, or *window*.
- Use **Select** instead of *press* (a physical button), *click* (with a mouse), or *touch* (by a finger).
- Use *select* and *clear* for checkboxes.
- Use *earlier* (about versions) instead of *lower* or *older*.
- Use *enter* instead of *type*.
- Use *later* (about versions) instead of *higher* or *above*.

## Useful phrases

1. Use "Complete the fields" to describe that the fields in the window or form must be filled in:
   - If the field is understandable from its label, do not provide explanations.
   - If only one field out of several needs explaining, give the explanation in the step or task.
   - If many fields need explaining, use a bulleted list.
2. Use "You can find answers to common questions or solutions to known issues in the broader ELITEA documentation" as standard phrasing for pointing readers to FAQs or troubleshooting content.

## Words to avoid

Avoid words that anchor text in time: *as of this writing*, *currently*, *does not yet*, *eventually*, *existing*, *future*, *in the future*, *latest*, *new*, *newer*, *now*, *old*, *older*, *presently*, *at present*, *soon*. The exception is release notes and press releases.

| Avoid | Better |
| --- | --- |
| allow, enable (this allows you to...) | can |
| easily, simply | None |
| above | For images and examples: *previous* or a direct link.<br/>For versions: *later*. |
| below | For images and examples: *following* or a direct link. |
| disable | turn off, hide, make unavailable or inactive, remove |
| downgrade | change to earlier or lower |
| enable | turn on, make active |
| navigate to | go to |
| need to | *must*, if something is required.<br/>*should*, if something is recommended.<br/>*can*, if something is optional. |
| respectively | Be precise. |
| utilize | use |

## Phrases to avoid

- "This page is about..."
- "This guide explains..."
