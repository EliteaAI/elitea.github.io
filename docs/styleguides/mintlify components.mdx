# Mintlify Components

## Accordions

### Alert boxes (Mintlify callouts)

**General rules**

- Use sparingly.
- Never use an alert after alert.
- Do not use blockquotes.

| Callout | Use for |
|---|---|
| `<Note>` | Additional information. Don't use notes to provide information that's necessary for the reader to succeed. |
| `<Warning>` | Deprecated features, legacy disclaimers and future-feature disclaimers. |
| `<Info>` | To be described. |
| `<Tip>` | Do not use because it is ambiguous. |
| `<Check>` | To be described. |
| `<Danger>` | Removed features. |
| `<Callout icon="lightbulb" color="#a855f7" title="">` | Custom callout: ELITEA tip. |
| `<Callout icon="book" color="#C9B896" title="See Also">` | Custom callout: See also. |

## Tabs

Tab titles:

- Be brief. Keep below 25 characters.
- Use parallel structures.
- Use sentence case.
- tbd

## Tooltips

Use for abbreviations (including acronyms and initialisms).

Do not use:
- for common abbreviations.
- at first use.
