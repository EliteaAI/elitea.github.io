# Writing style

Full standard: `docs/styleguides/language.mdx`, `wording and formatting.mdx`, `usage dictionary.mdx`. Apply to new and edited text only.

- Write in US English, second person, active voice, present tense.
- No contractions, no possessive `'s` on product names (not "ELITEA's").
- No Oxford comma. No en dashes; use hyphens in words and unspaced em dashes between them.
- No exclamation marks, ellipses or "please note".
- Use **Select**, not click or press. Use *enter*, not type. Use *dialog*, not pop-up or modal. Use *go to*, not navigate to.
- Avoid: allow/enable you to (use *can*), simply, easily, utilize, currently, now, new, latest, above, below.
- Use *must* (required), *should* (recommended), *can* (optional).
- Bold UI labels exactly as the UI shows them. Navigation paths: **Settings** > **Secrets**.
- Use inline code for field values, parameters, user input, paths and commands.
- Write location or reason, then action: "In **Settings**, select **Secrets**."
- Keep paragraphs to five sentences or fewer. Prefer clear explanatory prose to terse bullet fragments.
- Introduce every list and table with a sentence.
- Spell out zero to nine; numerals for 10 and up.
- Use fake data only: `user@example.com`, `<your_jira_token>`.
- Explain briefly inline instead of sending the reader to another page.
